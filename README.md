# Superkoda

This repository will be used by the [superkoda.com](https://superkoda.com) platform.

## About Superkoda

**Business apps you can change by asking.**

Superkoda provides prebuilt business apps that you customize with AI by describing
changes in plain language. Each app covers one job from start to finish and runs on
a shared platform that handles access control, documents, email, API access, and releases.

- **AI customization**: request new fields, rules, screens, and reports, then preview them
  on a development copy before releasing.
- **Reversible releases**: the database is snapshotted before each install, so you can
  roll back to an earlier version.
- **Multi-organization**: subsidiaries or customers share one installation, and each
  sees only its own data.
- **Role-based access**: the same permissions apply to screens, reports, and the API.
- **REST API**: every record type has list, detail, and edit screens plus a documented API.
- **Localization**: each user sets their own language, time zone, and number and currency formats.
- **Flexible hosting**: Superkoda cloud, your own servers, or a laptop for demos.

Learn more at [superkoda.com](https://superkoda.com).

## About Openkoda

**Openkoda** is an insurance policy administration system (PAS) that your team configures
with AI. It covers products from quote to claim and is built for MGAs and coverholders,
carriers, brokers, TPAs and claims administrators, and InsurTech or embedded insurance providers.

- **Build and configure**: AI Product Builder, Rating Engine, Workflow Engine, Forms & Distribution
- **Run the lifecycle**: Policy Administration, Underwriting, Claims, Billing & Payments,
  Document Generation, Reporting & Bordereaux
- **AI features**: Reporting AI, AI document reading, underwriting copilot, MCP server
- **Enterprise**: multi-tenancy, client and broker portals, APIs, managed cloud or on-premise deployment

Openkoda is no longer open source, and its source code is no longer published in this repository.

Learn more at [openkoda.com](https://openkoda.com).
